# render — сборка презентации

Собирает .pptx по слайдам сценария, манифесту шаблона (`theme`) и итогам движка.

- Всегда открывается рабочая копия шаблона; слайды шаблона из отчёта удаляются вместе
  со связями (слайды-образцы появятся на этапе M3).
- Слайд строится из макета роли, блоки ставятся в области макета. Блоки берутся из
  реестра плагинов, поэтому `render` не знает о `blocks-std`.
- Ошибка блока или его данных не останавливает сборку: на слайде появляется красная
  пометка «Ошибка: …», остальные слайды собираются.
- Если в тексте осталось `{{`, отчёт не сохраняется.
- Файл сохраняется атомарно; если он открыт в PowerPoint, рядом сохраняется «… (2).pptx».

`validate_slides` проверяет слайды без данных: макеты, области, параметры блоков,
ссылки на наборы и показатели.

Запуск отдельно — на сохранённых итогах (`agen run … --workdir папка` пишет их сам):

```
uv run python -m autogenerator.render examples/sales/scenario.yaml --theme папка/theme/manifest.json --data папка/engine/outputs --period 2026-03 -o отчёт.pptx
```

Тесты модуля: `uv run agen test render` (или `uv run pytest packages/render`).
