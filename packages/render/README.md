# render — сборка презентации

Собирает .pptx по слайдам сценария, манифесту шаблона (`theme`) и итогам движка.

- Всегда открывается рабочая копия шаблона, а не пустая презентация.
- **Слайд из макета** (`layout:`) строится из макета роли, блоки ставятся в области
  макета, элементы оформления роли (логотип обложки и т. п.) копируются под остальные
  фигуры вместе с картинками. Ошибка блока или его данных не останавливает сборку: на слайде появляется
  красная пометка «Ошибка: …».
- **Слайд-образец** (`example:` — id слайда шаблона) остаётся как в шаблоне:
  - метки получают значения (блок `markers`);
  - графики и таблица получают данные (`chart_fill`, `table_fill`).

  Незаполненная метка, график или таблица останавливает сборку, и все такие места
  показываются одним списком. Иначе в отчёте останутся демо-данные шаблона.
- Слайды встают в порядке сценария. Неиспользуемые слайды шаблона удаляются вместе со
  связями. Слайд-образец, взятый второй раз, копируется вместе с графиками, книгами Excel,
  заметками и тегами. Блоки берутся из реестра плагинов, поэтому `render` не знает о
  `blocks-std`.
- Перед сохранением:
  - части слайдов переименовываются по порядку;
  - разделы и `docProps/app.xml` переписываются по итоговым слайдам;
  - пустой список авторов примечаний удаляется.
- Если в слайдах, заметках или графиках осталось `{{` (кроме меток «оставить метку»), отчёт
  не сохраняется. То же, если в файле нашлись повторяющиеся части или ссылки без связей.
- Пробная сборка (`preview=True`, одного слайда — `only=N`) не останавливается на
  непривязанных метках: они подсвечиваются.
- Файл сохраняется атомарно; если он открыт в PowerPoint, рядом сохраняется «… (2).pptx».

`validate_slides` проверяет слайды без данных:
- макеты и области, параметры блоков, ссылки на наборы и показатели;
- для слайдов-образцов ещё:
  - слайды и фигуры шаблона по id;
  - привязку всех меток;
  - незаполненные графики и таблицы;
  - число серий графиков.

Запуск отдельно — на сохранённых итогах (`agen run … --workdir папка` пишет их сам):

```
uv run python -m autogenerator.render examples/sales/scenario.yaml --theme папка/theme/manifest.json --data папка/engine/outputs --period 2026-03 -o отчёт.pptx
```

Тесты модуля: `uv run agen test render` (или `uv run pytest packages/render`).
