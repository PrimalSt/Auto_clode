# theme — что приложение видит в шаблоне

Импортирует шаблон .pptx или .potx: делает рабочую копию (сам шаблон не меняется) и
записывает манифест.

- **Макеты и роли.** Макеты читаются во всех мастерах. Приложение предлагает макеты под
  роли, на которые ссылается сценарий: `title`, `section`, `title_and_content`,
  `title_and_two_content`, `title_text_and_content`, `title_only`, `blank`, `final`. Роль
  угадывается по имени макета («Обложка», «Раздел», «Последний» и т. п.) и по составу
  плейсхолдеров. Недостающая роль строится из ближайшего макета: «пустой» — из макета
  только с заголовком (заголовок удаляется), «финальный» — из титульного. Для каждой роли
  есть области для блоков (`title`, `subtitle`, `body`, `left`, `right`, `text`).
  Подтверждённые роли (`roles={"title_only": "<id макета>"}`) заменяют предложенные; если
  макет роли не подходит, это ошибка (`strict_roles`) или замечание при повторном импорте.
- **Элементы оформления.** Логотип, волна и другие декоративные фигуры титульного,
  разделительного и финального слайдов, которых нет на макете роли, записываются в
  `RoleBinding.decorations`, и `render` переносит их на новые слайды этой роли. Если такая
  же фигура есть на макете с `preserve="1"`, она берётся с макета (положение — со слайда):
  тогда элемент не пропадёт, если слайд удалят из шаблона.
- **Слайды-образцы.** Слайды шаблона перечисляются с метками `{{…}}` (в том числе
  разрезанными на прогоны), графиками (группы серий, вторая ось, наложенные графики,
  надписи под каждую категорию) и таблицами.
- **Проверка шаблона.** Ищет:
  - метки, которые нельзя заменить: перенос строки или поле внутри метки, метка в графике,
    SmartArt или заметках;
  - одинаковые метки на разных слайдах и повторы на одном;
  - вписанные вручную годы и ссылки на номера слайдов;
  - повторяющиеся имена фигур, фигуры за краем слайда;
  - макеты без геометрии;
  - шрифты шаблона, которых нет на компьютере.
- Файлы с макросами и архивы-бомбы не принимаются.

Посмотреть свой шаблон и получить заготовку слайдов сценария (файл не меняется):

```
uv run agen theme check "C:\Шаблоны\Корпоративный.pptx" --layouts
uv run agen theme scaffold "C:\Шаблоны\Корпоративный.pptx" -o слайды.yaml
uv run python -m autogenerator.theme шаблон.pptx --out манифест.json
```

С `--out` рядом с манифестом сохраняется рабочая копия шаблона (`манифест.template.pptx`):
по ним двоим собирает отчёт `python -m autogenerator.render`.

Зависит только от `contracts`.

Тесты модуля: `uv run agen test theme` (или `uv run pytest packages/theme`).
