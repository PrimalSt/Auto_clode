# theme — что приложение видит в шаблоне

Импортирует шаблон .pptx или .potx: делает рабочую копию (сам шаблон не меняется),
читает макеты всех мастеров и предлагает макеты под роли, на которые ссылается сценарий:
`title`, `section`, `title_and_content`, `title_and_two_content`, `title_only`, `blank`.
Для каждой роли — области для блоков (`title`, `subtitle`, `body`, `left`, `right`).
Слайды шаблона перечисляются с метками `{{…}}`, графиками и таблицами: это будущие
слайды-образцы (заполнение появится на этапе M3). Файлы с макросами не принимаются.

Посмотреть свой шаблон (файл не меняется и никуда не копируется, кроме временной папки):

```
uv run python -m autogenerator.theme "C:\Шаблоны\Корпоративный.pptx" --layouts
uv run python -m autogenerator.theme шаблон.pptx --out манифест.json
```

Зависит только от `contracts`.

Тесты модуля: `uv run agen test theme` (или `uv run pytest packages/theme`).
