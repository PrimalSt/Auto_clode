# contracts — общий язык модулей

Модели данных и интерфейсы, через которые модули говорят друг с другом. Здесь нет логики
обработки: только описания. Модуль не зависит ни от одного другого модуля приложения
(это проверяет `uv run lint-imports`).

Что внутри:

- `periods.py` — периоды отчёта: `Period` (месяц, квартал, год, неделя, день, диапазон),
  разбор строк `2026-03`, `2026-Q1`, `2026`, `2026-03-03..2026-03-19`, сдвиг на период назад
  и на год назад. Все отрезки полуоткрытые: `[start, end_exclusive)`.
- `sources.py` — источник выгрузки (`SourceSpec`): столбцы с типами и другими названиями
  (`aliases`), столбец периода и откуда период (`period_from`: столбец файла или загрузка —
  для выгрузок-срезов), правило пересечения загрузок.
- `snapshot.py` — снимок структуры файла с профилем столбцов, итог сверки столбцов, итог
  записи загрузки.
- `history.py` — загрузки источника (`HistoryManifest`), шкала покрытия (`CoverageReport`)
  и интерфейс `HistoryProvider`, через который движок получает историю, не зная, где она
  лежит.
- `storage.py` — записи папки данных (источник и версии его настроек, загрузка) и
  интерфейсы хранилищ `MetadataStore` и `BlobStore`; реализации — в пакете `storage`.
- `jobs.py` — задания исполнителя: `run` (собрать отчёт; `slide` — только один слайд,
  `preview` — мягкая проверка, `image` — картинка слайда), `ingest` (загрузить файл) и
  `preview` (превью узла сценария).
- `scenario.py` — сценарий отчёта: входы и шаги, наборы данных (группировка, сравнение
  периодов, расчёты, топ-N с «Прочими», сводная, запрос SQL, код Python), показатели
  (агрегат, формула, запрос, код, сравнение периодов), метки на всю презентацию
  (`markers`), слайды из макетов (`layout`) и слайды-образцы (`example`, `markers`, `keep`).
- `theme.py` — что приложение знает о шаблоне: макеты, роли макетов, области для блоков,
  слайды-образцы (`TemplateSlideInfo`: метки, графики с группами и сериями, таблицы),
  замечания проверки шаблона (`LintIssue`) и шрифты.
- `ooxml.py` — чтение разметки слайда (lxml): фигуры с координатами на слайде, включая
  группы, текст абзаца из прогонов и переносов, поиск меток `{{…}}` вместе с разбитыми на
  куски. Общее у `theme` (импорт шаблона) и `blocks-std` (подстановка).
- `plugins.py` — базовые классы плагинов (читатель, шаг, окно, агрегат, блок) и версия
  API плагинов `PLUGIN_API_VERSION`. 0.2: читатель сообщает прогресс, отдаёт шапку
  `columns` и выборку из начала, середины и конца файла. 0.3: шаг сообщает типы столбцов
  результата (`output_schema`), глубину истории, которая ему нужна (`lookback`), другие входы
  (`inputs_used`), ключи для выборки превью (`key_columns`), можно ли кэшировать результат
  (`cacheable`) и замечания до запуска (`check`); `StepContext` даёт шагу SQL в DuckDB
  (`sql`), формулы и условия с запасным путём через DuckDB (`with_column`, `filter`), другие
  входы (`input`), запуск кода пользователя (`run_code`) и признаки `large` и `preview`.
  0.4: блок указывает, что он заполняет (`target_kind`: место макета, метки, график или
  таблица слайда-образца), проверяет привязку до запуска (`check`) и доделывает слайд после
  всех своих блоков (`finish_slide`); `BlockTarget.example` — манифест слайда-образца,
  `BlockContext.keep_marker` — метка остаётся на слайде намеренно.
- `results.py` — статусы узлов, замечания, итоги движка, сборки, запуска и превью
  (`PreviewResult`).
- `errors.py` — коды ошибок и `AgenError` с подсказкой пользователю.
- `yaml_io.py` — чтение и запись YAML, понятные сообщения об ошибках в спецификациях.

Пример:

```python
from autogenerator.contracts import Period

p = Period.parse("2026-03")
p.shift(-1).key        # '2026-02'
p.years_ago().key      # '2025-03'
p.span                 # DateSpan(start=2026-03-01, end_exclusive=2026-04-01)
```

Правило: изменение контракта — это изменение для всех модулей сразу. Несовместимое
изменение интерфейсов плагинов меняет `PLUGIN_API_VERSION`.

Тесты модуля: `uv run agen test contracts` (или `uv run pytest packages/contracts`).
