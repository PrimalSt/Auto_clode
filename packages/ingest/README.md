# ingest — чтение выгрузки и запись загрузки

Два шага:

1. `inspect_file` — снимок структуры: как прочитан файл, названия столбцов, выведенные
   типы и примеры значений. Русские форматы распознаются: `1 234,56` (в том числе
   с неразрывными пробелами), `(1 500,00)` для отрицательных, `29.09.2026`,
   `29.09.2026 14:30`, «да/нет». Тип выбирается, если распознаны 98% значений выборки.
2. `write_upload` — запись файла в Parquet, разложенный по месяцам столбца периода
   (`month=2026-03/part-0.parquet`). Столбцы переименовываются в `id` источника
   и приводятся к его типам; добавляются служебные `_upload_id`, `_upload_seq`, `_row`.
   Нераспознанные значения становятся пустыми, исходные строки кладутся в
   `rejects.parquet`, а загрузка с ошибками в нужных сценарию столбцах получает статус
   «на проверку». Загрузка пишется во временную папку и переименовывается целиком.

Читателей `ingest` берёт из реестра плагинов и сам о них не знает.

Запуск отдельно:

```
uv run python -m autogenerator.ingest examples/sales/data/sales/Продажи_2026-02.csv
uv run python -m autogenerator.ingest План.xlsx --sheet План --header-row 2 --json
```

Тесты модуля: `uv run agen test ingest` (или `uv run pytest packages/ingest`).
