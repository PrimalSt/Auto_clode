# ingest — чтение выгрузки и запись загрузки

1. `inspect_file` — снимок структуры: как прочитан файл (кодировка, разделитель, листы,
   строка заголовков), названия столбцов, выведенные типы, примеры значений, профиль по
   выборке и первые строки. Выборка — начало, середина и конец файла. Русские форматы
   распознаются: `1 234,56` (в том числе с неразрывными пробелами), `(1 500,00)` для
   отрицательных, `29.09.2026`, `29.09.2026 14:30`, «да/нет». Тип выбирается, если
   распознаны 98% значений выборки; числа с ведущими нулями, целые от 10 цифр (лицевые
   счета, номера договоров) и столбцы вроде «ИНН», «Код», «Номер» остаются текстом, «T/F» —
   логический тип. `header_snapshot` — снимок только по шапке (для Excel, чтобы
   не читать лист дважды).
2. `write_upload` — запись файла в Parquet, разложенный по месяцам столбца периода
   (`month=2026-03/part-0.parquet`). Столбцы переименовываются в `id` источника и
   приводятся к его типам; добавляются служебные `_upload_id`, `_upload_seq`, `_row`
   (номер строки файла). Чтение, приведение типов и запись идут одновременно в разных
   потоках; порции сразу пишутся на диск. Пустые строки пропускаются. Нераспознанные
   значения становятся пустыми, исходные строки кладутся в `rejects.parquet`, а загрузка с
   ошибкой в столбце периода или с долей ошибок больше 0,1% в нужном столбце получает
   статус «на проверке». Загрузка пишется во временную папку и переименовывается целиком;
   отмена (`cancelled`) и сбой не оставляют половины. Прогресс — через `progress`.
   Выгрузка из нескольких файлов (`more=[FilePart(...)]`) пишется одной загрузкой: файлы
   читаются по очереди, `_row` продолжается, строки с ошибками — в `rejects/<n>.parquet` со
   столбцом `_file`. `fixed_period` заполняет столбец периода у выгрузки-среза.
3. `profile_upload` — точный профиль записанной загрузки: пустые, уникальные (на миллионах
   строк — оценка), минимум, максимум и пять самых частых значений у текстовых и целых
   столбцов, где значений немного. Один проход на все столбцы и по проходу на частые
   значения, поэтому на 10 млн строк — до 1 ГБ памяти.

Читателей `ingest` берёт из реестра плагинов и сам о них не знает.

Запуск отдельно:

```
uv run python -m autogenerator.ingest examples/sales/data/sales/Продажи_2026-02.csv
uv run python -m autogenerator.ingest План.xlsx --sheet План --json
```

Тесты модуля: `uv run agen test ingest` (или `uv run pytest packages/ingest`).
