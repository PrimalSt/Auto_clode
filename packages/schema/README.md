# schema — сверка структуры

Сопоставляет столбцы нового файла со столбцами источника: по названию или по другим
названиям (`aliases`), без учёта регистра, «ё/е», знаков препинания и лишних пробелов.
Так февральский файл с «Сумма, руб.» вместо «Сумма» и переставленными столбцами читается
как тот же источник. Если точного совпадения нет, названия сравниваются без месяцев:
«Были ли покупки в апреле» подходит к «… в январе» (только если такой столбец в файле
один). Столбец периода, который задаётся при загрузке (`period_from: upload`), в файле не
ищется.

Итог `reconcile`:

- `ok` — все нужные сценарию столбцы нашлись; лишние столбцы файла перечислены;
  отсутствующие ненужные столбцы в этой загрузке будут пустыми (если их всё же использует
  сценарий, о котором загрузка не знала, — предупредит запуск);
- `needs_review` — нужный столбец не нашёлся по названию, но в файле есть похожий:
  кандидаты (`candidates`, до трёх лучших) оцениваются по названию (0,5), типу (0,2) и
  значениям — по профилю прежних загрузок (0,3); если какой-то оценки нет, остальные
  перевзвешиваются. Пара с оценкой от 60% предлагается в `proposed`, но только если второй
  кандидат заметно хуже; столбцы, по которым нужно решение, — в `review`. Несовместимый тип
  (текст вместо числа) не предлагается;
- `blocked` — нет нужного сценарию столбца (или столбца периода), и похожего тоже нет.
  Сообщение называет столбец, названия, под которыми его искали, и кто от него зависит.

Какие столбцы нужны: `required` — их используют сценарии; `None` — неизвестно (источник
ещё не используют сохранённые сценарии), тогда о каждом пропавшем столбце с вероятной
заменой спрашивается подтверждение. Ненужный сценариям переименованный столбец даёт только
предупреждение «похоже, это …». `declined` — столбцы, которые пользователь оставил пустыми:
их не предлагают снова. `with_aliases` добавляет подтверждённые названия в `aliases`
источника (F-605).

`draft_source` — черновик источника по снимку первой выгрузки: латинские `id` столбцов
(«Дата заказа» → `order_date`, «Скидка, %» → `discount_pct`, незнакомые слова — транслитом),
типы и форматы дат, столбец периода (первый столбец с датами, где в названии есть «дата»
или «период»), кодировка и разделитель. Названия месяцев в id становятся `month`, чтобы id
не зависел от месяца выгрузки. С `period_from=upload` (выгрузка-срез без столбца с месяцем)
в источник добавляется столбец «Период загрузки». Какой столбец взять периодом и тип
периода решает `worker` по датам.

Какие столбцы нужны сценарию, говорит `engine.column_usage`. Модуль зависит от `contracts`
и `rapidfuzz` (сходство названий). Подтверждение сопоставления — `Home.upload` и
`agen upload add --map/--accept-mapping`; экран сопоставления — в окне приложения.

Тесты модуля: `uv run agen test schema` (или `uv run pytest packages/schema`).
