# worker — сборщик модулей

Единственное место, где модули обработки встречаются. Метаданные `worker` не открывает:
всё нужное приходит в задании, а результат фиксирует тот, кто задание поставил.

**Задание `ingest`** (`ingest_upload`) — загрузить файл в историю источника:

1. Снимок структуры (`ingest`): по выборке, а у Excel — только по шапке, чтобы не читать
   лист дважды.
2. Сверка с источником (`schema`): нет нужного столбца — загрузка не начинается.
3. Запись Parquet по месяцам (`ingest`) с прогрессом и отменой.
4. Период загрузки, строки вне периода, пересечения с прежними загрузками (`history`).
5. Точный профиль столбцов (`ingest`).

`draft_source` — черновик источника по выгрузке (`schema`), тип периода — по датам
(`history`).

**Задание `run`** — собрать отчёт:

1. Проверка сценария (`engine.analyze`), импорт шаблона (`theme`), проверка слайдов
   (`render.validate_slides`) — до чтения данных.
2. История каждого входа: из папки данных (манифест приходит в задании) или из файлов —
   тогда каждый файл проходит задание `ingest` во временную историю.
3. Отчётный период: заданный или по умолчанию по основному входу (`history`).
4. Расчёт (`engine`) с историей из `history.history_view`, затем сборка (`render`).
5. С `slide` в задании собирается один слайд сценария (пробная сборка, `preview` —
   непривязанные метки не останавливают её), с `image` — ещё и его картинка
   (`slide_image`: PowerPoint через COM в Windows, иначе LibreOffice).

**Задание `preview`** — превью узла сценария без сборки .pptx: читаются только входы, от
которых узел зависит (`engine.preview`). Кэш узлов и временные файлы — в папке данных
(`cache_dir`, `temp_dir` в задании), поэтому повторное превью берёт выборку и готовые
результаты из кэша.

С `workdir` все промежуточные данные остаются на диске: загрузки, манифесты истории,
манифест шаблона, результаты входов, наборы и показатели. На них можно перезапустить
любой модуль отдельно (см. README модулей). Без `workdir` используется временная папка.

**Оформление** (`theme_jobs.py`): `import_theme` — импорт и проверка шаблона,
`describe_theme` — отчёт о шаблоне, `scaffold_theme` — заготовка слайдов для сценария.

Пока `worker` вызывается прямо из `api`; очередь заданий и отдельные процессы
исполнителей (`runner`) появятся вместе с приложением.

Тесты модуля: `uv run agen test worker` (или `uv run pytest packages/worker`).
