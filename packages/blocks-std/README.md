# blocks-std — встроенные блоки слайдов

Плагины `render`. Зависят только от `contracts` (и `lxml` для разметки графиков и таблиц).

## Слайды из макетов

Заполняют места макета (`slot`).

- `text` — текст с переменными (Jinja2 в песочнице): `{{ metrics.revenue | money(scale='million', decimals=1) }}`,
  `{{ period.label }}`, `{{ change_pct(metrics.revenue, metrics.revenue_prev) | percent(sign=true) }}`.
  Пустое значение печатается как «нет данных», неизвестная переменная — ошибка блока.
- `chart` — «родная» диаграмма PowerPoint: `column`, `stacked_column`, `bar`, `stacked_bar`,
  `line`, `pie`, `doughnut`. Данные встраиваются, график можно править в PowerPoint.
  Даты в категориях — по-русски («янв. 2026»); столбцы и полосы начинаются от нуля.
- `table` — таблица PowerPoint с русскими форматами чисел, процентов и дат;
  пустое значение — «—».

## Слайды-образцы

Заполняют готовые фигуры слайда шаблона (`shape` — id фигуры, его показывает
`agen theme check --verbose`). Оформление остаётся как в шаблоне.

- `markers` — метки `{{Имя}}` в тексте фигур слайда (в группах и таблицах тоже). Привязки
  задаются полем `markers` слайда и сценария (на всю презентацию); блок собирает их сам.
  Короткая запись: `Месяц: period.month` (переменная периода, `period.Month` — с заглавной
  буквы) или `Выручка: revenue` (id показателя). Полная запись — `metric`, `period`, `text`
  или `value` плюс формат числа (ниже) и `empty`: что делать, если значения нет (`stop` —
  остановить сборку, `blank` — оставить пустым, `keep` — оставить метку). Привязка к одной
  фигуре — `Имя@id`, к одному вхождению — `Имя@id#номер`; действует самая точная. Метка,
  разбитая PowerPoint на несколько кусков текста, заменяется целиком, формат первого куска
  сохраняется.
- `chart_fill` — данные набора в готовый график: `dataset`, `categories` (столбец категорий)
  и `series` (столбцы в порядке серий шаблона: `column`, `name`, `number_format`, `scale`)
  или `series_from` — серии из данных (ниже).
  Цвета, подписи, оси, вторая ось комбинированного графика и легенда — из шаблона. Другое
  число серий — `groups` (по группам графика, например `[3, 1]`). Круговая получает не больше
  секторов, чем в шаблоне (`max_points`), остальное — в сектор «Прочие». Подписи линии и
  столбцов на комбинированных графиках разводятся по полосам (ARCHITECTURE.md, раздел 6.5),
  `labels: off` это отключает. Если рядом с графиком надписи стоят под каждую категорию,
  число категорий должно совпасть с шаблоном (`expected_categories` проверяет и порядок).
- `table_fill` — набор в готовую таблицу: `columns` (столбцы по порядку, `header` и формат
  числа у каждого), `other_columns: true` — после них все остальные столбцы набора (удобно
  для таблиц со сводной по месяцам: «2026-01» в заголовке становится «янв. 2026»), `number` —
  их формат. Строки копируют оформление первой строки данных шаблона, ширина первых
  `fixed_columns` столбцов сохраняется, остальные делят оставшееся место. Кегль — `font_size`,
  иначе как в ячейках шаблона, иначе унаследованный: стиль прочего текста образца слайдов,
  стиль презентации, 18 пт. Строки не ниже, чем в шаблоне (новые — как первая строка данных);
  если так таблица не помещается до `bottom` (по умолчанию — до четверти дюйма от низа
  слайда), высота строк считается по тексту, затем кегль уменьшается до `min_font_size`,
  затем остаются последние строки с предупреждением.

  Заливка ячеек данных: `fill` у столбца — столбец набора с цветом `RRGGBB` для каждой строки
  (в `other_columns` он не попадает; пусто — заливка шаблона). `heatmap` — тепловая карта, как
  условное форматирование Excel: `columns` (столбцы таблицы), `min` и `max` (пусто —
  наименьшее и наибольшее значение в ячейках карты), `colors` (по умолчанию красный `F8696B`,
  жёлтый `FFEB84`, зелёный `63BE7B` — равномерно от `min` до `max`; цвет из одних цифр — в
  кавычках, `"999999"`, иначе YAML прочтёт его как число). Значение — число набора
  или текст вида «45,0%» (читается как 45); пустые и нечисловые ячейки («-») сохраняют
  заливку шаблона. Непустой цвет из `fill` важнее карты, текст ячеек не меняется.

Формат числа (`values.py`, метки и ячейки): `decimals`, `scale` (`thousand`, `million`,
`billion` или «тыс.», «млн», «млрд»), `sign` («+» у положительных), `percent` (0,125 → 12,5%),
`points` (0,012 → 1,2 п.п.) и `unit`. Если в шаблоне сразу после метки уже стоит «%» или
«п.п.», значение подставляется без своей единицы.

Пример слайда-образца в сценарии:

```yaml
slides:
  - example: 257                 # id слайда шаблона
    markers:
      Выручка: {metric: revenue, scale: million, decimals: 1}
      Прирост+: {metric: revenue_prev_change_pct, percent: true, sign: true, empty: blank}
    blocks:
      - type: chart_fill
        shape: 6
        dataset: month_mix
        categories: month
        series: [big, small, {column: big_share, number_format: "0%"}]
```

Таблица удержания когорт: доли по месяцам жизни (`age_1`, `age_2`, …) раскрашены от красного
(0) через жёлтый к зелёному (1), ячейка когорты — цветом из столбца `cohort_color`:

```yaml
      - type: table_fill
        shape: 4
        dataset: retention
        columns:
          - {column: cohort, header: Когорта, fill: cohort_color}
          - {column: clients, header: Клиентов}
        other_columns: true            # age_1, age_2, … — после них
        number: {percent: true, decimals: 0}
        heatmap: {columns: [age_1, age_2, age_3, age_4, age_5, age_6], min: 0, max: 1}
```

### Цвет значения по знаку

`color` у привязки метки перекрашивает подставленное значение (текст вокруг метки остаётся
как в шаблоне): `color: sign` — положительное зелёным (`2E7559`), отрицательное красным
(`C00000`), ноль — цветом шаблона; `color: "1F4E79"` — один цвет при любом знаке. Полная
запись — `positive`, `negative`, `zero` (RGB; пусто — цвет шаблона) и `by` — показатель, по
знаку которого выбирается цвет. Без `by` знак берётся из показателя привязки, у `text` и
`value`, а также если показатель пуст, — из самого текста: «+» — положительное, «-» или «−» —
отрицательное, иначе ноль. Цвет пишется в кавычках: без них YAML прочитает `2E7559` как
число, а `#2E7559` — как комментарий.

```yaml
markers:
  Изменение_: {text: "({{ metrics.score_diff | number(sign=true) }}%)", color: sign}   # «(+3%)» зелёным
  Выручка: {metric: revenue, scale: million, decimals: 1, color: {by: revenue_prev_change_pct}}  # зелёным, если выросла
```

Знак показателя (`by` или показателя привязки) берётся до округления: при `score_diff = 0.3`
«(0%)» с `color: {by: score_diff}` станет зелёным, а с `color: sign` (знак из текста) — нет.
Пустой `by` не подменяется показателем привязки: выручка без прошлого периода остаётся цвета
шаблона.

### Серии из данных

Когда число серий зависит от данных (каналы, регионы, продукты), вместо `series` задаётся
`series_from`: `column` — столбец с названиями серий, `value` — столбец со значениями,
`number_format` и `scale` — общие для всех серий. Набор «длинный» — строка на категорию и
серию; серий столько, сколько разных названий, как в сводной таблице. Категории идут в порядке
появления в наборе, пропущенная пара категории и серии — 0, повторы складываются, строки без
названия серии пропускаются с предупреждением. Порядок серий `order`: `name` (по умолчанию) —
по названию (числа и даты — по возрастанию, как в сводной таблице), `data` — по первому
появлению, список названий — сначала они, потом остальные по названию. Если серий больше, чем
в шаблоне, новые получают свои цвета; если меньше, лишние серии шаблона удаляются (и о том и
о другом — предупреждение). Только для графика с одной группой серий, не круговой; `groups`
вместе с `series_from` не задаётся.

Регистрации по каналам:

```yaml
datasets:
  - id: regs_by_channel            # строки: месяц, канал, число регистраций
    input: registrations
    window: quarter_to_date
    group_by: [{ column: date, bucket: month }, channel]
    aggregate: [{ fn: count, as: regs }]
    sort: [date]

slides:
  - example: 258
    blocks:
      - type: chart_fill
        shape: 4
        dataset: regs_by_channel
        categories: date
        series_from:
          column: channel          # каналы — серии графика
          value: regs
          order: [Сайт]            # сначала «Сайт», остальные каналы по названию
```

## Форматы

`formats.py`: `1 234 568`, `26,2 млн ₽`, `12,5%`, `+1,2 п.п.`, «март 2026»,
«I квартал 2026», «3–19 марта 2026», месяцы в падежах (`period.month_prep` — «марте»).
Разряды и единицы отделяются неразрывным пробелом.

Тесты модуля: `uv run agen test blocks-std` (или `uv run pytest packages/blocks-std`).
