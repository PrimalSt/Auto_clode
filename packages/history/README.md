# history — история загрузок и периоды

Чистые функции над манифестом истории: модуль ничего не пишет и не знает, откуда
манифест взят.

- `upload_period` — период загрузки по датам в ней: выгрузка с 9 по 31 января — «январь
  2026»; захватывает несколько месяцев — диапазон из целых месяцев.
- `history_view` — ленивая таблица действующей истории по правилу пересечения источника:
  - `replace_period` — более новая загрузка заменяет строки старых за свой период
    (повторная выгрузка января заменяет январь);
  - `merge_dedupe` — все загрузки, по ключу (`keys`) остаётся версия из самой новой;
  - `replace_all` — только последняя загрузка;
  - `append` — все строки всех загрузок;
  - `ask` — у каждой загрузки, период которой пересекается с прежними, своё правило,
    выбранное при загрузке (`UploadRef.overlap_policy`); загрузка без пересечений просто
    добавляется.
  Месяцы вне нужных границ не читаются. Столбец, добавленный в источник позже, в старых
  загрузках пустой.
- `default_report_period` — отчётный период по умолчанию: загрузка с самым поздним концом,
  поэтому дозагрузка старого месяца его не сдвигает.
- `coverage` — за какие даты есть загрузки; по нему движок предупреждает о пропусках.
- `uploads_in` — какие загрузки читаются за отрезок дат: активные, чей период пересекается
  с отрезком и не заменён там целиком более поздними (`replace_period`, `replace_all`). По
  ним и по `UploadRef.file_columns` движок предупреждает о столбцах, которых не было в файле.
- `coverage_report` — шкала покрытия для экрана истории: по единицам типа периода (длинная
  шкала укрупняется), какие покрыты, где пропуски, где загрузки накладываются.
- `overlapping_uploads` — с какими загрузками пересекается период новой; `rows_outside` —
  сколько строк загрузки лежит вне её объявленного периода; `guess_period_type` — тип
  периода по датам первой выгрузки; `period_from_name` — период по имени файла
  («Продажи_2026-01», «01.2026», «Feb», «январь», «mart»; без года — последний такой месяц).
- У источника-среза (`period_from: upload`) столбец периода в истории — период загрузки из
  метаданных, поэтому правка периода (`agen upload period`) видна сразу, файлы не
  переписываются.

Запуск отдельно (манифест пишет `agen run … --workdir папка` или `agen history <источник> --json`):

```
uv run python -m autogenerator.history папка/manifests/sales.json --out история/sales.parquet
```

Тесты модуля: `uv run agen test history` (или `uv run pytest packages/history`).
