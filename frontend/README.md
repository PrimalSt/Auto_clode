# frontend — окно приложения

React-интерфейс поверх локального сервера (`packages/server`, ARCHITECTURE.md, разделы 6.8 и 10).
Окно не читает папку данных и не считает само: всё идёт запросами к серверу, долгие действия —
заданиями, о ходе и изменениях сервер сообщает потоком событий. В оболочке (этап M4, часть 4)
окно открывается в WebView; без оболочки — в браузере по адресу сервера.

## Разделы

| Раздел | Что там |
|---|---|
| Источники | список, создание по первой выгрузке, столбцы (типы, другие названия), история загрузок с покрытием периодов, загрузка с выбором сопоставления столбцов, версии настроек |
| Сценарии | список и мастер нового сценария; конструктор (входы и шаги, наборы, показатели, слайды) с превью выбранного места на данных из истории; код YAML с проверкой по схеме; версии со сравнением; запуски сценария |
| Оформление | шаблоны .pptx: роли макетов, слайды-образцы с метками, проверка, версии |
| Запуски | собранные отчёты, журнал узлов, пересборка за прошлый период |
| Модули | исполнители, модули и плагины, кэш, резервные копии |

Сценарий в окне — это его YAML. Конструктор правит тот же текст: меняются только строки
затронутого места, комментарии и порядок остаются (`features/scenarios/draft.ts`). Схему
сценария для форм и редактора кода окно берёт у сервера (`GET /api/schemas/scenario`): в ней
параметры установленных модулей и короткие записи вроде `window: last_n(6)`.

## Разработка

Нужны Node.js 22 и uv. Сервер — из корня репозитория, окно — отсюда:

```
uv run agen serve --dev --port 8765      # печатает токен
npm ci
npm run dev                              # http://localhost:5173/#token=<токен>
```

Vite отправляет запросы `/api` на сервер (`AGEN_API`, по умолчанию `http://127.0.0.1:8765`).

| Команда | Что делает |
|---|---|
| `npm run build` | проверка типов и сборка в `packages/server/src/autogenerator/server/ui` — оттуда окно отдаёт сервер |
| `npm run typecheck` | проверка типов |
| `npm test` | тесты (Vitest) |
| `npm run api` | типы API (`src/shared/api/schema.d.ts`) заново по OpenAPI сервера; нужно после изменения моделей сервера |

CI проверяет, что `schema.d.ts` совпадает с сервером, типы, тесты и сборку.

## Устройство

- `app/` — каркас: меню, состояние связи с сервером, задания в работе.
- `features/<раздел>/` — экраны раздела и его запросы (TanStack Query).
- `shared/api/` — клиент (`openapi-fetch` по `schema.d.ts`), токен, задания, поток событий.
- `shared/components/` — общие части: таблица данных (AG Grid), редакторы кода (Monaco),
  ошибки и замечания, ход задания.
- `shared/monaco/` — Monaco и воркеры собираются вместе с окном, интернет не нужен.

Библиотеки: React 19, Mantine 9, TanStack Query 5, zustand 5, Monaco (`monaco-yaml` —
проверка и подсказки YAML), AG Grid Community, `yaml`.
