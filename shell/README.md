# shell — оболочка для Windows (Tauri)

Программа `autogenerator.exe`: окно приложения, запуск локального сервера и надзор за ним
(ARCHITECTURE.md, раздел 4.1). Код — на Rust, окно — WebView2 через Tauri 2. Сам интерфейс
отдаёт сервер: окно открывает `http://127.0.0.1:<порт>/`, поэтому оболочка не знает разделов
приложения и не меняется вместе с ними.

## Как работает

1. Окно открывается со стартовой страницы оболочки (`ui/index.html`, «Запускаю приложение…»).
2. Оболочка запускает `python -m autogenerator.server --port 0 --parent <pid> --home <папка>`
   без окна консоли и с токеном в переменной `AGEN_TOKEN`, ждёт строку `AGEN_SERVER_READY`
   и переводит окно на адрес сервера. Страницам сервера оболочка добавляет `window.__AGEN__`:
   токен, системный выбор файлов и папок, открытие отчёта в PowerPoint, перетаскивание
   файлов в окно, папку данных и режим разработчика (`frontend/src/shared/api/client.ts`,
   тип `ShellBridge`).
3. Сервер и все его процессы (исполнители, тесты модулей) — в объекте задания Windows:
   закрылась оболочка, даже аварийно, — Windows завершает их всех. Каждому процессу —
   предел памяти, 80 % физической: расчёт, которому её не хватило, получает ошибку памяти
   в своём исполнителе, а компьютер не зависает.
4. Упал сервер — оболочка запускает его снова. Три сбоя подряд или ошибка, которую повтор
   не исправит (например, папку данных держит другая программа), — **безопасный режим**
   на стартовой странице: повторить, запустить без режима разработчика, вернуться к
   последнему удачному запуску, выбрать другую папку данных или папку по умолчанию,
   открыть журналы.
5. Окно закрывают, пока идут задания, — оболочка спрашивает, прервать ли их. При выходе
   сервер останавливается сам (`POST /api/system/shutdown`): закрывает базу и исполнители.

Окно переходит только на стартовую страницу и на адрес текущего сервера; другие ссылки
открываются в браузере. Команды оболочки (`src/app.rs`) разрешены только этим страницам
(`capabilities/default.json`).

## Настройки

`%APPDATA%\Autogenerator\shell.json` (другая папка — переменная `AGEN_SHELL_CONFIG`):

```json
{"home": "D:\\Отчёты\\данные", "dev_source": null, "last_good": {"home": null, "dev_source": null}}
```

- `home` — папка данных; `null` — по умолчанию (`AGEN_HOME` или `%LOCALAPPDATA%\Autogenerator`,
  как у `agen`). Меняется в окне: «Модули» → «Приложение на этом компьютере».
- `dev_source` — **режим разработчика**: копия исходников (папка с `pyproject.toml`, после
  `uv sync`), из которой запускается сервер (`.venv\Scripts\python.exe`). Поправили модуль —
  «Проверить и применить» на экране «Модули»: сначала проходят тесты изменённых модулей,
  и только потом исполнители перезапускаются с новым кодом; не прошли — всё работает
  по-старому.
- `last_good` — с чем сервер в последний раз запустился: к этому возвращает безопасный режим.

Журнал оболочки — `shell.log` рядом с настройками; журнал сервера — `logs\server.log` в папке
данных.

## Служебные режимы

```
autogenerator.exe --self-test [--home ПАПКА] [--report ФАЙЛ]
autogenerator.exe --register
autogenerator.exe --unregister
```

- `--self-test` — проверка установки без окна: тот же Python, объект задания и токен, что у
  окна; здоровье сервера, токен, сведения о системе, исполнители и манифест модулей,
  интерфейс, остановка. Без `--home` — временная папка данных (данные пользователя не
  трогаются). Код выхода 0 — всё прошло.
- `--register` / `--unregister` — их зовёт установщик (`windows/hooks.nsh`): папка `bin`
  с `agen.cmd` — в PATH пользователя, Python приложения — ядро Jupyter «Autogenerator»
  (`%APPDATA%\jupyter\kernels\autogenerator`).

## Разработка

Нужны Rust (stable) и собранный интерфейс; на Linux ещё библиотеки WebKitGTK
(`libwebkit2gtk-4.1-dev` и др., см. документацию Tauri).

```
cd frontend && npm ci && npm run build && cd ..   # интерфейс — в пакет сервера
uv sync
cd shell
cargo run                                         # окно; Python — .venv репозитория
cargo run -- --self-test                          # проверка без окна
cargo test && cargo clippy --all-targets && cargo fmt --check
```

Вне установки оболочка ищет Python так: переменная `AGEN_PYTHON`; в режиме разработчика —
`.venv` копии исходников; `python\python.exe` рядом с программой (установка); `.venv`
репозитория, внутри которого собрана программа.

## Установщик

Собирается на Windows (в CI — задание «Установщик», `.github/workflows/installer.yml`):

```
cd frontend && npm ci && npm run build && cd ..
uv run --no-project python tools/build_bundle.py  # build\bundle: python, bin, sdk
cd shell && npm ci && npm run installer           # target\release\bundle\nsis\*-setup.exe
```

- Установка — для текущего пользователя, без прав администратора, в
  `%LOCALAPPDATA%\Autogenerator`. Это же папка данных по умолчанию: имена не пересекаются,
  а удаление стирает только файлы программы (данные, отчёты и журналы остаются).
- В установщике — Python приложения со всеми библиотеками по `uv.lock` (`python\`), команда
  `agen` (`bin\agen.cmd`), пакеты модулей и версии библиотек для своего окружения (`sdk\`)
  и WebView2 для установки без интернета.
- CI ставит собранный установщик тихо (`/S /D=…`), запускает `--self-test`, проверяет `agen`
  и ядро Jupyter, удаляет и проверяет, что PATH и ядро убраны; установщик — в артефактах.
- Подписи пока нет: нужен сертификат подписи кода. Без неё Windows SmartScreen при первом
  запуске предупреждает о неизвестном издателе («Подробнее» → «Выполнить в любом случае»).

## Файлы

| Файл | Что |
|---|---|
| `src/main.rs` | точка входа: окно или служебный режим |
| `src/app.rs` | окно, мост `window.__AGEN__`, команды, надзор за сервером, безопасный режим |
| `src/server.rs` | поиск Python, запуск сервера, строка готовности, остановка |
| `src/job.rs` | объект задания Windows: завершение вместе с оболочкой, предел памяти |
| `src/settings.rs` | `shell.json`, папка данных по умолчанию, журнал оболочки |
| `src/register.rs` | PATH пользователя и ядро Jupyter |
| `src/selftest.rs` | `--self-test` |
| `src/http.rs` | короткие запросы к серверу (здоровье, остановка, число заданий) |
| `ui/index.html` | стартовая страница и безопасный режим |
| `tauri.conf.json`, `tauri.bundle.conf.json` | окно и установщик (второй — ресурсы и NSIS) |
| `icons/` | значки (`uv run python tools/make_icons.py`) |
